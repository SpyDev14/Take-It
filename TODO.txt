1. Клиент должен обрабатывать команды, клиент должен с помощью них находить файл / папки
2. Сервер должен переправлять файл от клиента к клиенту
3. Клиент должен уметь получать файл
4. Клиент должен уметь искать файл
5. Клиент должен уметь находить сервер
6. Клиент не должен ломаться, если работает несколько серверов
